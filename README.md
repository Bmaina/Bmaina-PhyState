# PhyState

**Physical Reality Assurance** — verifying what AI agents believe about the physical world.

PhyState is a verification layer for lenders and insurers who rely on AI agents to make decisions about physical assets they can't see. It checks whether what the agent believes is happening on the ground is actually true — using independent satellite evidence — before money moves.

**Live site:** https://bmaina.github.io/phystate *(update once deployed)*

## What this repo is

A single self-contained landing page (`index.html`) for PhyState, built to deploy directly on GitHub Pages. No build step, no dependencies beyond two Google Fonts links loaded at runtime.

## Deploying

1. Push this repo to GitHub (e.g. `Bmaina/phystate`)
2. In the repo's **Settings → Pages**, set the source to the `main` branch, root directory
3. The site will be live at `https://<username>.github.io/<repo-name>/`

## Content source

Page content is drawn directly from the PhyState pitch deck (Claim → Evidence → Assurance → Action framing, validation status, business model, market sizing, competitive positioning, team, and ask). It intentionally mirrors the deck's disclosed gaps — no customer, no domain co-founder, hypothesis-stage pricing — rather than smoothing them over, since that honesty is part of what makes the pitch credible.
